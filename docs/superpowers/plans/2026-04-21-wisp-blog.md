# wisp-blog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a static personal notes site with Astro 4.x — scholarly serif design, light/dark mode, Pagefind search, pagination, KaTeX math, Mermaid diagrams, Shiki syntax highlighting, and Cusdis comments.

**Architecture:** Astro 4 static site with content collections. All articles live in `src/content/articles/` (imported once from `.claude/context/notes/notebook/src/`). Everything is static HTML generated at build time. Client-side JS is limited to: theme toggle (inline `<head>` script), Pagefind search UI (post-build), Mermaid ESM renderer, and Cusdis comment embed.

**Tech Stack:** Astro 4, TypeScript strict, pnpm, `remark-math`, `rehype-katex`, `unist-util-visit`, Pagefind 1.x CLI, Shiki (Astro built-in, dual Rosé Pine themes), Cusdis hosted (cusdis.com), Maple Mono (fontsource CDN), KaTeX CSS (CDN), Mermaid.js ESM (CDN).

- [ ] **Step 2.1: Create `src/lib/remark-mermaid.ts`**

This remark plugin converts ` ```mermaid ` code blocks to `<div class="mermaid">` HTML nodes *before* Shiki sees them, so Shiki never tries to highlight an unknown language.

```bash
mkdir -p src/lib
```

```ts
import { visit } from 'unist-util-visit';

export function remarkMermaid() {
  return (tree: any) => {
    visit(tree, 'code', (node: any, index: any, parent: any) => {
      if (node.lang !== 'mermaid' || !parent || index === undefined) return;
      parent.children.splice(index, 1, {
        type: 'html',
        value: `<div class="mermaid">${node.value}</div>`,
      });
    });
  };
}
```

- [ ] **Step 2.2: Create `src/lib/articles.ts`**

```ts
import { getCollection, type CollectionEntry } from 'astro:content';

export const SECTIONS = ['About', 'Independent Study', 'MSCS'] as const;
export type Section = (typeof SECTIONS)[number];
export const PER_PAGE = 10;

const SECTION_ORDER: Record<Section, number> = {
  About: 0,
  'Independent Study': 1,
  MSCS: 2,
};

export function readingTime(body: string): number {
  return Math.ceil(body.split(/\s+/).filter(Boolean).length / 200);
}

export async function getSortedArticles(): Promise<CollectionEntry<'articles'>[]> {
  const articles = await getCollection('articles');
  return articles.sort((a, b) => {
    const sectionDiff = SECTION_ORDER[a.data.section] - SECTION_ORDER[b.data.section];
    if (sectionDiff !== 0) return sectionDiff;
    const dateA = a.data.date?.getTime() ?? 0;
    const dateB = b.data.date?.getTime() ?? 0;
    if (dateA !== dateB) return dateA - dateB;
    return a.data.title.localeCompare(b.data.title);
  });
}

export interface PageResult {
  articles: CollectionEntry<'articles'>[];
  currentPage: number;
  totalPages: number;
  hasNext: boolean;
  hasPrev: boolean;
}

export function paginateArticles(
  articles: CollectionEntry<'articles'>[],
  page: number,
): PageResult {
  const start = (page - 1) * PER_PAGE;
  const end = start + PER_PAGE;
  return {
    articles: articles.slice(start, end),
    currentPage: page,
    totalPages: Math.ceil(articles.length / PER_PAGE),
    hasNext: end < articles.length,
    hasPrev: page > 1,
  };
}
```
